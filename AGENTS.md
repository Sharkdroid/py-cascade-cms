# AGENTS.md

`cascade-cms-rest` — a typed, async REST client for Hannon Hill Cascade CMS 8.
Library source is `src/cascade_cms/`.

## Repo commands

```bash
pip install -e ".[dev]"
pytest
ruff check .
mypy src/
```

CI runs `ruff check .`, `mypy src/`, and `pytest`. Run all three before
considering a change to the library done.

## Writing scripts that use this library

Two skills, same validator, same library snapshot:

| Skill | Use it for |
|---|---|
| `skill/cascade-script-writer/` | Multi-operation pipelines, callback patterns, anything no template covers. 21 templates, full JSON schema. |
| `skill/cascade-script-writer-lite/` | Single-operation scripts, and any small/fast model. 6 templates, one generated `references/OPS.md`, ~3.5k tokens to read instead of ~16k. |

The lite skill forbids reading `cascade_cms/*.py` — that snapshot is there for
the validator to import, not to be used as documentation. Its `OPS.md` is
generated by `skill/gen_ops_reference.py`; never hand-edit it.

Start from a template:

```bash
cd skill/cascade-script-writer
python scripts/new_script.py --list
python scripts/new_script.py --template create-bulk --out my_script.py
```

Then validate:

```bash
python skill/cascade-script-writer/scripts/validate_script.py my_script.py
```

**A generated script is complete only when `validate_script.py` exits 0.** Fix
what it reports and re-run; cap at 3 attempts, then surface the output verbatim
rather than looping.

Two rules the validator enforces and scripts must never break:

- `CascadeWrapperBase` is the only entry point — no `cascade_cms.driver`, no
  manual asyncio event loop, no hand-built `aiohttp.ClientSession`.
- `Asset` fields are written by attribute (`asset.keywords = value`), never by
  subscript (`asset["keywords"] = value` raises `TypeError`).

## Rebuilding the skill

```bash
python skill/build_skill.py                 # both bundles
python skill/build_skill.py --target lite   # one of full|lite|all
```

Syncs `src/cascade_cms/` into each skill bundle, rewrites the manifest,
validates every template, and zips. The lite build also regenerates `OPS.md`,
re-copies its templates and scripts from the full skill, and fails if
`SKILL.md` or `OPS.md` outgrows its size budget. Never copy the snapshot by
hand — a stale bundle makes the validator reject correct scripts.
